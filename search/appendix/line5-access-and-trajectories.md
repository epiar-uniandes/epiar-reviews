# Search appendix — Line 5: Access and educational trajectories

Search terms by sub-intervention and language, as registered in the OSF
protocol for Line 5 of the Education Portfolio Impact Assessment Report
(EPIAR 1.0).

Terms are entered as quoted phrases and combined with the Boolean operator
OR within each sub-intervention. One query is run per sub-intervention and
language. Spelling, hyphenation, accent and plural variants are specified
explicitly rather than relying on each source's stemming. Outcome,
empirical design and geographic terms are not included in the queries and
are considered during screening. A date restriction from 1990 onward is
applied using the available search options in each source.

## Adaptation by source

**OpenAlex.** Terms in all three languages, restricted to titles and abstracts.

**ERIC.** English terms only, as the database indexes non-English records
with English titles and abstracts.

**World Bank Open Knowledge Repository.** Each quoted phrase is searched
separately and combined with an education term in the corresponding
language, since the repository covers all sectors and does not accept a
single Boolean block. Records are then pooled and deduplicated.

**3ie Development Evidence Portal.** The same quoted phrases are entered
through the web interface, with the education sector filter applied.
