# EPIAR 1.0 — Reproducibility repository

This repository holds the search strategies, code, prompts, data and analysis
for the six parallel systematic reviews conducted as part of the Education
Portfolio Impact Assessment Report (EPIAR 1.0), commissioned by the
Inter-American Development Bank (IDB) and carried out by researchers
affiliated with Universidad de los Andes.

Each review covers one intervention line of the IDB education portfolio:

| Line | Intervention line |
|------|-------------------|
| 1 | School infrastructure and equipment |
| 2 | Teacher development |
| 3 | Curriculum and assessment |
| 4 | School management and governance |
| 5 | Access and educational trajectories |
| 6 | Educational technology and innovation |

The six protocols are registered separately on the OSF Registries and apply
common methods, differing only in the intervention line, its sub-interventions,
eligible outcomes, and search strings.

OSF project: https://osf.io/zu5cj

## Status

Under construction. Protocol development and registration are in progress.
No searches have been conducted for eligibility purposes, no screening
decisions have been made, and no data have been extracted or analyzed.

## Contents

Contents will be added as the reviews progress:

- `protocols/` — registered protocol text for each line, with a link to its OSF registration
- `search/` — search appendix by sub-intervention and language, search code, and retrieval logs
- `screening/` — screening code and the prompt used for title and abstract screening
- `extraction/` — extraction template, coding manual, and the prompt used for extraction
- `analysis/` — analysis code reproducing all tables and figures reported in the reviews
- `data/` — deduplicated records with stage and reason for exclusion, and the extracted effect sizes

All files are provided in open formats. No personal or confidential
information is included, as all data come from published or publicly
available sources.
